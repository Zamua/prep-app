{# Mastery bar macro: green/red/empty progress track for the deck page header. The dashboard row renders the same markup at its smaller `--mini` size from static/js/dashboard/components.js. Parameters: - mastered: int, count of mastered cards - wrong: int, count of cards last answered wrong - total: int, total cards in the deck #} {% macro bar(mastered, wrong, total) %} {%- set _t = total or 1 -%} {%- set _mp = (100 * mastered / _t) -%} {%- set _wp = (100 * wrong / _t) -%} {% endmacro %}
